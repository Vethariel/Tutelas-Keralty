# Triaje asistido de tutelas

Reto Kantera – Universidad Nacional de Colombia · Clínica Universitaria Colombia (Keralty / Colsanitas)

Propuesta de apoyo para leer, clasificar, priorizar y direccionar tutelas, pensada para líderes asistenciales y administrativos sin formación jurídica. La solución **sugiere**; toda decisión la revisa y confirma una persona.

## Propuestas

| | Propuesta A: Piloto en la clínica | Propuesta B: Plataforma para la red Keralty |
|---|---|---|
| Idea | Solución austera con las herramientas que la clínica ya tiene | Plataforma propia para las clínicas de la red |
| Tecnología | Google Apps Script, Drive, Sheets, Looker Studio | Backend, PostgreSQL y frontend web propios |
| Entregable en el reto | Prototipo funcionando | Arquitectura, mockup, hoja de ruta y costos |

## Insumos del reto

La carpeta `insumos/` contiene el documento de antecedentes y la base sintética de 60 casos entregados por Kantera. **Está excluida del repositorio** (`.gitignore`) porque el documento de antecedentes incluye nombres de personas de la clínica y no hay confirmación de que el material pueda publicarse. Quien trabaje en el proyecto debe pedirlo al equipo y guardarlo localmente en esa carpeta.

## Aviso

Material de uso académico. Todos los casos, textos y correos de prueba son ficticios. Este repositorio no autoriza el tratamiento de información sensible ni la intervención en el proceso institucional de tutelas. **No subir datos reales de pacientes, expedientes ni documentos judiciales.**
